# 이미지 제작 가이드 — 배경 / 캐릭터 분리 방식 (영어 프롬프트)

게임은 **배경(인물 없음)** 위에 **캐릭터 스프라이트(누끼 PNG)** 를 얹는 방식입니다.
이 폴더에 아래 **파일명 그대로** 넣으면 자동 적용되고, 없으면 그라데이션/캐릭터 생략으로 정상 동작합니다.

- 배경: `.jpg`, **세로 9:16**, 인물 없음 → 형제/자매 공용 (한 번만 만들면 됨)
- 캐릭터 스프라이트: `.png`, **배경이 투명한 누끼**, 무릎 위(knee-up) 세로 구도
- 프로필: `char-male.png` / `char-female.png` (1:1, 닉네임 화면용)

## 제작 순서

1. **STEP 1** 기준 얼굴 생성 → `char-male.png` 저장
2. **STEP 2** 그 사진을 첨부하고 포즈 6종 생성 (흰 배경으로 나옴)
   → **remove.bg** (무료)에 넣어 배경 제거 → 투명 PNG로 `sprite-***-m.png` 저장
3. **STEP 3** 배경 7장 생성 (첨부 없이)
4. 자매는 나중에 STEP 4
