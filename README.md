# 천국상사(주) 경력직 채용 — REMIND RESTART

수련회용 미연시(비주얼 노벨) 게임. 참가자들이 각자 폰으로 플레이하며,
실물 이력서 작성 · 간증 나눔 · 면접관(하나님) 시점 심사 등 오프라인 활동과 연결됩니다.

## 미리보기 방법

윈도우 탐색기에서 `D:\수련회post\index.html` 을 더블클릭 → 브라우저에서 바로 실행.
(폰 화면 비율로 보려면 브라우저에서 F12 → 기기 모드 아이콘 클릭)

현재는 **데모 모드**: "전원 완료 대기" 화면에서 화면을 탭하면 다음으로 넘어갑니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 참가자용 게임 (진입점) |
| `admin.html` | **진행자 콘솔** — 게이트별 도착 인원 실시간 확인 + [다음으로 진행] 버튼 |
| `js/story.js` | **모든 대사·텍스트** — 내용 수정은 이 파일만 |
| `js/engine.js` | 화면 렌더링 엔진 (수정할 일 거의 없음) |
| `js/sync.js` | 게이트 동기화 (설정 없으면 데모 모드, 설정하면 Firebase 실전 모드) |
| `js/firebase-config.js` | Firebase 설정 + 진행자 비밀번호 (`ADMIN_PIN`, 기본 1004) |
| `css/style.css` | 디자인 |

## 동기화 진행 (실전 모드)

`js/firebase-config.js` 를 채우면 자동으로 실전 모드가 됩니다 (설정 방법은 그 파일 안 주석 참고).
진행자 음악을 한 스피커로 트는 것을 전제로, **아무도 먼저 다음 장면으로 넘어갈 수 없습니다.**

- **🎵 장면 전환 동기화 9곳 (자동)**: 시작·방·카페·합격·교회·면접장·최종발표·입사·엔딩.
  전원이 도착하면 자동으로 함께 넘어갑니다 → 이 순간이 음악 전환 타이밍.
- **①~⑥ 진행자 게이트 6곳 (수동)**: 지원서 시작/완료, 스터디 시작/완료, 면접 심사, 실천 계획.
  진행자가 `admin.html` 에서 **[다음으로 진행]** 을 눌러야 넘어갑니다.
- 진행자 콘솔(`admin.html`)에는 15개 지점이 시간순으로 표시되고, 지점별 도착 인원·이름이
  실시간 갱신됩니다. 자동 지점도 이탈자가 생기면 **[강제 진행]** 으로 열 수 있습니다.
- 리허설 후에는 진행자 콘솔 맨 아래 **[전체 초기화]** 를 눌러 기록을 지우세요.

## 게임 흐름

1. 타이틀 → 형제/자매 선택 + 이름 입력 (실명 — 사원증·합격자 발표에 사용)
2. 프롤로그: 평범한 일상 → 사랑인(사람인 패러디) 푸시 알림 → 채용공고(패러디) → 지원하기
3. **Ch.1 REMIND**: 지원서 작성 장면 → "지원서 작성 중…" 오버레이 → 실물 이력서 작성 → 작성 완료 → 전원 대기
4. "3일 후…" → 서류 합격 문자 → 면접 스터디(= 조별 간증 나눔, 나눔 질문 3개) → 전원 대기
5. 면접 당일 → **시점 전환: 면접관 모드** → 자기 이력서를 다시 읽고 합격/탈락 선택(비공개) → 전원 대기
6. 어떤 선택이든 → 하나님의 목소리 → **합격 도장** (이사야 43:1) → 스크린으로 조각말씀 시청
7. 최종 합격 문자 → **디지털 사원증** 발급 (캡처 유도)
8. **Ch.2 RESTART**: 입사 첫날 → 입사 포부 작성(실물) → 전원 대기 → 포부 나눔
9. 마지막 조각말씀 시청 → 엔딩 (신명기 8:2 REMIND + 이사야 43:19 RESTART) → 스크린에서 최종 합격자 발표
